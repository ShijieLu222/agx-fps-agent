## 攻守行为

### 守方：观察入口，然后出击

有地图候选站位时，不再把包点中心当作防守终点。依据公开入口、守点提示、导航连接及箱体轮廓，选择与中心分离的站位，按席位分散。观察入口约 1.5 秒后，推进至朝进攻方来路的导航节点；每处短看约 0.75 秒，最多两处后回到集结位置再选择。前压点限制在包点周围 24 米内，避免无情报直奔对方出生点。

当前可见敌人触发交战；连续无进展的前压目标退出候选；无视野受伤优先沿实际走过的地面路线短撤。前压时不会把“离开原守位”误判成守位寻路失败。没有可用地图候选时保留导航降级行为，不声称所有地图都能安全前压。

队友从存活变为阵亡时，立即根据其合法区域信息转去支援，目标有效 12 秒，重复看到同一具尸体不会不断刷新。区域对应包点且存在守点候选时，先去入口站位，不强制冲包点中心。未知区域、首次观察已经死亡、跨回合遗留死亡均不触发伪情报。

**信息限制：** 当前合同的 `teammates` 只有存活、区域及允许装备等字段，没有队友看见的敌人列表、精确位置或 HP。五场日志未提供可核实语义的敌情报点；本版不猜测其他 agent 的数值信号。因此实现的是“阵亡区域支援＋本人声音/视野响应”，不能声称已知道队友每次发现敌人的瞬间。

### 回防：下包改道，遇敌先打，清完再拆

一旦下包，炸弹目标立即取代常规前压和支援。优先使用合法观察到的炸弹位置；仅知道包点则先去该点；都不知道时依次搜索公开包点。

回防途中，当前可射击的敌人优先于赶路，不再因倒计时紧或远距离对枪超过两秒而背对敌人继续走。即使已经到拆包范围，仍看见敌人就不开始/继续拆包；无弹时允许装填。视野清空且到达可交互位置后，停稳并连续拆包。此选择符合此次明确要求，但不能保证残局一定来得及拆除。

### 攻方：进点后继续清理通道

开局立即推进；非携包者从合法炸弹携带者位置判断其接近哪个包点，跟随该点。进入包点后继续推进到朝守方方向的附近导航节点，不在中心无限停住。接敌时停稳射击，失去视野后的等待有上限，再恢复推进。

携包者保留下包任务和远距离交战时间预算。下包后观察守方来路，取消持续原地转圈。突击不等于边跑边乱射：转角或近处声音可短暂减速，但没有声音/视野证据时不凭空开火。

## 修复对应的问题

| 原问题 | 本版变化 | 验证 |
|---|---|---|
| 到包点即停住，盲转等死 | 分离入口站位、短观察、前压、支援和回防 | 站位/推进闭环及状态切换用例 |
| 久站覆盖掉退路，受伤只转头 | 以空间距离记录最多 64 个实际地面轨迹点；站立不覆盖 | 站立 60 秒、受击后逐段绕角回退；跳跃/传送使旧轨迹失效 |
| 射击检查早一 tick，步枪变慢 | 仅数值 `shot_ready` 按动作首次执行的 `tick+1` 判断 | 独立 60Hz 武器时钟产生 AK/M4 的 6-tick 间隔；切枪、装填、布尔 readiness 仍按当前时刻 |
| 近距也机械断火 | 近距且散布可控时持续请求连射，远处仍控连发 | 枪械节奏、空弹/空中/移动/失去视野禁射 |
| 永远瞄胸部 | 近距、姿态稳定、地面低速且散布小时选头；远距收紧角误差 | 头部选择门槛及带转向/蹲姿变化的闭环射击 |
| 忽略脚步方向 | 近/中距左右声道短时锁定观察方向，并在接近时减速 | 实际右侧脚步历史片段及无身份声音不产生目标 |
| 武器经济断层、无头盔 | 主步枪优先；连败且留得出护甲预算时可买 Galil/MP9；有主武器与护甲后补头盔 | 预算门槛及装备顺序测试 |

本版没有加入投掷物、队伍统一经济或学习模型。公开导航连通、箱体轮廓和地图提示不等于完整三角网格碰撞验证，也不证明某站位一定有掩护。

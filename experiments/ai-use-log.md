# AI 使用记录

记录真实发生的辅助过程；由团队补充本人理解、复核与取舍，不把 AI 产出自动当作正确结论。

## 2026-11-15 / 项目初始化

- 工具：Codex。
- 用户任务：阅读作业与比赛要求，说明 FPS agent 开发和迭代方法，准备公开 GitHub 仓库。
- AI 工作：核对作业评分、当前官方 FPS 接口和预算；基于官方 starter 做运行健壮性修复；建立打包、离线日志检查与测试；准备迭代记录模板。
- 依据：课程作业材料、AGX 官方 FPS 开发指南、官方示例源码与工具包。
- 已执行的自动核验：Python 单元测试与代码审查。没有正式排名赛证据。
- 重要纠正：课程要求两个游戏；上传不等于已激活参赛；官方工具包不是完整模拟器；历史观察重放不能证明胜率提高。
- 团队人工复核：待团队填写。

## 2026-11-15 / v1 优化与首次上传

- 工具：Codex；用户授权查看 AGX、上传最新代码、网上研究公开策略并优化。
- AI 工作：通过已登录 Chrome 核对参赛排期、报名并上传；审查官方基线；检索其他 AGX 公开策略及通用 FPS bot；独立实现距离 A*、目标交互和装备状态修复。
- 研究取舍：没有找到可确认的其他 AGX 参赛者公开策略；查阅 YaPB 和 Recast/Detour，借鉴原则，未复制源码。没有引入隐藏敌人状态或运行时 LLM。
- 核验：26 项本地测试通过；合成图 CPU 计时；ZIP 根仅 `agent.py`；平台显示 v1 通过验证且自动采用，指纹与本地包一致。
- 局限：合成计时不是平台整局预算证明；没有正式对局或胜率提升证据；武器数值时钟还需本人真实日志核验。
- 关联：见[迭代日志 v1](iteration-log.md)和[策略参考](../docs/strategy-references.md)。
- 团队人工复核与个人贡献：待团队填写，AI 执行不代表团队成员已完成理解和复核。

## 2026-11-15 / v2 朋友策略审查、融合与重新发布

- 工具：Codex。用户提供朋友策略 ZIP 并要求分析、选择性融入自己的 v2 和重新参赛。
- AI 工作：检查包结构和代码、比对内嵌地图与官方工具包；复现布尔时钟、地图失效、过近拆包阈值和投掷优先级问题；选择性重新实现交战节奏、合法观察记忆及分工，保留 v1 修复。
- 独立复核：实现与测试由不同审查过程交叉验证；最后审查额外修复接触时切枪会打断既有装填的问题，并加入回归。
- 核验：45 项测试、30,000 次合成回调协议检查、合成导航计时与可复现打包；平台 v2 校验通过并自动启用，指纹一致。
- 边界：没有使用隐藏敌方输入，没有复制整份朋友程序，没有正式对局或胜率提升证据；多个改动尚需用本人比赛做消融。
- 团队人工理解与贡献：仍由团队真实填写；AI 自动执行不代表成员已经完成复核。
